Conventions for every Verify task below, the same as specs 007 to 013:

- **Build and gates (targeted, per the user's 2026-10-20 instruction):** run `pnpm lint && pnpm typecheck && pnpm format:check`, then `npx electron-vite build`. Do NOT run the full unit or e2e suites in slice Verify tasks. They run once, in the last slice: `pnpm test:unit`, then `pnpm test:e2e`.
- **Tests come first:** write the failing test before the code it covers. Where an existing test pins the old behaviour (the header button, the dialog, a card), rewrite it to the new behaviour in the same task that changes the code; do not delete coverage without a replacement.
- **Fakes only:** the fake CLIs and a temp HOME (`HARNESS_CLAUDE_BIN`, `HARNESS_CODEX_BIN`, `HARNESS_E2E=1`, `HARNESS_USER_DATA`).
